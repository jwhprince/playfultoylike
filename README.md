# Какое-то медиа

Статическая визитка на HTML, CSS и JavaScript. Без npm, сборки, CDN, аналитики и внешних запросов. Шрифты и фотографии лежат локально.

## Запуск

```sh
python3 -m http.server 8080
```

Открыть http://localhost:8080. Для проверки используйте HTTP-сервер: строгая CSP и локальное хранилище могут вести себя иначе при открытии файла через `file://`. Автоматическая перезагрузка Live Server использует внедряемый скрипт, который CSP может блокировать; обычное обновление страницы работает.

## Публикация

Загрузить `index.html`, `style.css`, `app.js`, `theme.js` и `assets/` на статический хостинг. Все пути относительные, поддерживается размещение в подпапке. `public/`, `scripts/`, `codex/` и оригиналы логотипов посетителям не требуются.

В `deploy/_headers` — конфигурация CSP, защиты от встраивания страницы, MIME sniffing и доступа к устройствам для совместимого хостинга. Скопируйте её в корень публикации как `_headers`; на других серверах задайте эквивалентные HTTP-заголовки. CSP в HTML действует и без конфигурации сервера, но `frame-ancestors` работает только в HTTP-заголовке. HTTPS и сжатие Brotli/gzip включаются на стороне хостинга. У ресурсов нет хешированных имён, поэтому шаблон требует перевалидации кеша, чтобы обновления не застревали у посетителей.

## Тема и анимации

При первом открытии используется тема устройства. Кнопка в шапке переключает день/ночь и запоминает выбор в `localStorage` (`kakoe-media-theme`). При запрете хранилища переключение продолжает работать. Маленький `theme.js` применяется до CSS, чтобы сохранённая тёмная тема не мигала светлым фоном.

Бегущая строка состоит из двух одинаковых частей. Есть пауза кнопкой и при наведении мыши; `prefers-reduced-motion` отключает анимации. Карточки появляются один раз при прокрутке, без скрытия контента при отсутствии JavaScript.

## Фотографии

Оригиналы: `public/images/<категория>`. Корневые `logo.png` и `logo1.png` исключены из галереи.

```sh
python3 scripts/prepare_images.py
```

Требуется Pillow. Скрипт создаёт WebP до 720/1600 пикселей и `assets/gallery.js`. Категории и количество на сайте берутся из данных автоматически. `preferredCategories` в `app.js` задаёт порядок, `curated` — избранные фотографии.

При добавлении/удалении фото проверьте ID избранных работ и фотографии главного экрана в `index.html`: ID зависят от сортировки путей. Исходные фотографии не перезаписываются.

## Логотипы

```sh
python3 scripts/prepare_brand.py
```

Pillow удаляет серую шахматную подложку, очищает палитру и создаёт прозрачные копии, WebP и иконки. Упрощённая версия используется в шапке, подвале и favicon; детализированная — в контактах. Светлая наклейка сохраняет читаемость исходной тёмной обводки в обеих темах. Исходные PNG остаются без изменений.

## Контакты

Telegram и Instagram — локальные ссылки-заглушки: открывают окно с пояснением и никуда не отправляют данные. Без JavaScript ведут к пояснению на странице. Для реальных профилей замените `href`, уберите `data-social` и обновите `aria-label`; затем удалите текст о демонстрационных ссылках. При `target="_blank"` добавьте `rel="noopener noreferrer"`.

## Шрифты

Локальные DejaVu сокращены до латиницы, кириллицы и символов интерфейса: около 60 КБ вместо 488 КБ. Лицензия: `assets/fonts/LICENSE.txt`. Для обновления набора нужен `fonttools[woff]` и `scripts/subset_fonts.py`; необязательный аргумент — папка с исходными `body.woff2` и `display.woff2`. Из уже сокращённых файлов удалённые символы восстановить нельзя.

## Проверки

```sh
python3 scripts/audit_assets.py
python3 scripts/audit_browser.py
```

Первый скрипт проверяет локальные файлы, данные галереи и HTML. Второй требует сервер на 8080 и отдельный Chromium с DevTools на 9222:

```sh
chromium --headless --disable-gpu --remote-debugging-port=9222 --remote-allow-origins=http://localhost:9222 --user-data-dir=/tmp/kakoe-media-chrome about:blank
```

Он проверяет обе темы, семь ширин экрана, контраст текстов, размеры кнопок, галерею, модальные окна, клавиатуру, тему ОС, сохранение выбора, анимации и делает замер с ограничением сети/CPU. Скриншоты и JSON: `/tmp/kakoe-audit/`. Итоги и границы проверки описаны в `AUDIT.md`.

## Векторные детали и касания

Иконки из `public/images/придумаем.svg`, `изготовим.svg`, `соберемразберем.svg`, `смайлик.svg`, `перваязвезда.svg`, `втораязвезда.svg` встроены в `index.html`. Пути рисунков сохранены, пустые редакторские группы удалены, цвет наследуется от темы. Исходные SVG не изменены.

В строке две одинаковые группы по 41 слову. При изменении списка обновлять обе; длительность цикла задаётся для `.ticker-track` в `style.css` (280 с, на большом экране 340 с).

Эффекты наведения применяются к мыши. Сенсорные нажатия получают класс `is-touching`: отклик виден ещё 180 мс после отпускания, при прокрутке и отмене жеста сразу снимается. Обработчики не блокируют прокрутку, делегирование охватывает дозагруженные кнопки галереи.
