# дИАБЕТаРТгуу

Статическая визитка на HTML, CSS и JavaScript. Нет сборки, npm, внешних шрифтов, CDN, аналитики и сетевых библиотек.

## Запуск

Из корня проекта:

```sh
python3 -m http.server 8080
```

Открыть http://localhost:8080. Также можно открыть `index.html` напрямую.

## Публикация

На любой статический хостинг загрузить `index.html`, `style.css`, `app.js` и папку `assets`. Папки `public`, `scripts` и `codex` для работы сайта не нужны. Пути относительные, сайт можно разместить в подпапке.

## Фотографии

Оригиналы — `public/images/<категория>`. Генерация WebP двух размеров и `assets/gallery.js`:

```sh
python3 scripts/prepare_images.py
```

Нужен Python с Pillow. При добавлении категорий обновить `categoryNames` в `app.js`. Порядок избранных фото задаётся массивом `curated`. При изменении состава оригиналов проверить номера фотографий главного экрана в `index.html` и `curated`: номера генерируются по алфавитному порядку путей.

## Контакты

Контакты намеренно не вымышлены: кнопка открывает окно-заглушку. Перед публикацией заменить блок `#contact` и окно `.contact-dialog` реальными контактами, обновить обработчики в `app.js`.

## Возможности

Фильтры по шести категориям, дозагрузка, просмотр крупного фото, стрелки клавиатуры, свайпы, Escape, возврат фокуса, адаптивная сетка, поддержка reduced motion. Шрифты размещены локально, лицензия — `assets/fonts/LICENSE.txt`.
